# 🏥 PolyclinicApp (Медицинская информационная система)

Полноценное десктопное приложение для автоматизации работы поликлиники. Разработано на C# WinForms.

## ✨ Функциональные возможности

### 🔐 Авторизация
- Вход по логину и паролю
- Разграничение прав доступа (разные роли)

### 👤 Управление пациентами
- Картотека пациентов (номер карты, ФИО, дата рождения, социальный статус)
- Отслеживание состояния пациента (лечится, вылечился, умер)

### 👨‍⚕️ Управление врачами и диагнозами
- Справочник врачей (ФИО, специализация)
- Справочник диагнозов (наименование заболевания)

### 📋 Назначение лечения
- Привязка: пациент → врач → диагноз
- Дата начала лечения
- Срок нетрудоспособности (дней)
- Флаги: амбулаторное лечение, диспансерный учёт
- Автоматическое обновление состояния пациента

### 📊 Отчёты (сложные SQL-запросы)
1. Случаи лечения конкретного диагноза конкретным врачом-специалистом
2. Врачи, работающие исключительно с пенсионерами
3. Процент смертности от заболевания
4. Пациенты, которые болели (болеют) всеми болезнями (реляционное деление)

## 🛠 Технологии
- C# WinForms
- MS SQL Server / SQLite
- ADO.NET, сложные SQL-запросы (JOIN, подзапросы, GROUP BY, HAVING, деление)

## 🔑 Тестовый вход
- Логин: `admin`
- Пароль: (твой пароль)
